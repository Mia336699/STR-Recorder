# Chaturbate 适配

本版本保留 Stripchat 原有适配，并通过 `streaming/platform.rs` 选择各站点客户端。Chaturbate 使用独立适配器，不使用 Stripchat 镜像和 CDN 竞速。

## 平台标识

原有主播名 `alice` 继续表示 Stripchat；Chaturbate 使用 `chaturbate~alice`。标识贯穿监测、录制、事件、文件夹和后处理，两站同名频道不会互相覆盖。用户界面显示原用户名与平台名。

## 公开直播

通过站点播放器的 `get_edge_hls_url_ajax/` 查询公开状态，必要时回退解析页面 `initialRoomDossier`。仅为公开房间选择 HLS，解析标准相对路径与媒体序号，支持 TS 和 fMP4。独立音轨与视频按一致的媒体序号复用，再进入原录制与合并流程。API/CDN 代理沿用设置，但平台客户端保持独立。

缩略图直接使用站点当前的 `thumb.live.mmcdn.com`，避免旧域名失效。状态轮询更新图片 URL，前端提供加载失败占位。

## 边界与验证

不提供登录、验证码处理、私密或付费直播访问。403、验证页、地区限制和未知响应会报错。加密 HLS、字节范围流和 partial segments 尚未适配；独立音视频分片要求使用一致的序号，否则报错并重试。

测试覆盖中文站 URL 和平台身份、直播状态、Unicode dossier、分辨率回退、相对路径与滑动窗口、原 Mouflon 序号兼容及非法播放列表。两项显式 FFmpeg 验收验证独立 fMP4 音视频复用和两个平台的本地合成流下载、停止、合并及解码。2026-10-11 的真实公开直播验收完成约 41.5 秒 1080p H.264/AAC 录制，退出收尾和启动恢复通过；未执行长时间压力测试或通知发送。
